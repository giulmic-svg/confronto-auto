# Confronto Auto Diesel vs Elettriche

Applicazione Streamlit per confrontare i costi di esercizio e ammortamento tra un'auto diesel e varie auto elettriche.

## Deploy su Streamlit Cloud

1. Carica questa cartella su GitHub.
2. Vai su https://share.streamlit.io
3. Clicca "New app".
4. Seleziona il repository.
5. Scegli il file `app.py`.
6. Premi "Deploy".

L'app sarà disponibile online con un link pubblico.
